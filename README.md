# Abdullah — Video Editor Portfolio

This folder contains the static portfolio page and its six cover images, ready to publish with GitHub Pages.

## Publish

1. Create a new **public** GitHub repository named `abdullah-video-editor`.
2. Upload every file in this folder to the repository root.
3. In the repository, open **Settings → Pages** and select **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
4. Once GitHub Pages finishes publishing, the site will be at `https://<your-github-username>.github.io/abdullah-video-editor/`.
